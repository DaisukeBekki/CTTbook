# Cubical Type Theory - Chapter PDFs

Claude Code (Opus 5.0 / Fable 5) with Daisuke Bekki, *Introduction to Cubical Type Theory*, draft.

## この資料について

本資料は、cubical type theory の原論文2本

- Cyril Cohen, Thierry Coquand, Simon Huber, and Anders Mörtberg.
  *Cubical Type Theory: A Constructive Interpretation of the Univalence Axiom.*
  TYPES 2015 (LIPIcs 69), 2018. [arXiv:1611.02108](https://arxiv.org/abs/1611.02108)
- Thierry Coquand, Simon Huber, and Anders Mörtberg.
  *On Higher Inductive Types in Cubical Type Theory.*
  LICS 2018. [arXiv:1802.01170](https://arxiv.org/abs/1802.01170)

の解説に、独自の原稿を加えて構成した入門書のドラフトです。独自部分には、
導入章（関数外延性・UIP の導出不可能性の証明）、hcomp / transp を primitive
とする提示の再構成とその動機付け、整数型 **Z** を高次帰納型として構成する章
（算術・正規形定理・集合性）、トーラスの例、演習問題などが含まれます。

本文は **Claude Code**（Anthropic; Opus 5.0 / Fable 5）が
**戸次大介（お茶の水女子大学）の supervision のもとで生成**した原稿です
（戸次の関与は構成への提言と本文の修正）。生成 AI による原稿であることを
踏まえてお読みください。誤りの報告・改善提案は Issues へお寄せください。

- **言語**: 現在は日本語ドラフトです。
- **前提知識**: Martin-Löf 型理論（依存型・同一性型・自然数型の除去子）。
- **機械検証**: 第5章（整数型）の構成は Cubical Agda で型検査済みです:
  [AgdaTutorial-LatticeTheory](https://github.com/DaisukeBekki/AgdaTutorial-LatticeTheory)
  （`IntCancel` モジュール。本文が「判断的に成り立つ」と主張する等値性は
  開いた変数のまま `refl` で通過することを確認しています）。

  （内容に変更のあった章のみコミットされます）。
